3. Inheritance, composition, encapsulation

Inheritance застосовано там, де є справжнє is-a. GradingPolicy – ABC з абстрактним average; кожен підклас оголошується з іменем (class SimpleAverage(GradingPolicy, name="simple")) і реєструється через __init_subclass__, тому фабрика GradingPolicy.create(name) знає всі стратегії без жодного списку. BudgetStudent і ContractStudent є студентами: базовий has_scholarship повертає False, а бюджетний підклас перевизначає його.

class GradingPolicy(ABC):
    name: ClassVar[str]
    _registry: ClassVar[dict[str, type["GradingPolicy"]]] = {}

    def __init_subclass__(cls, *, name: str, **kwargs: Any) -> None:
        super().__init_subclass__(**kwargs)
        cls.name = name
        GradingPolicy._registry[name] = cls

    @classmethod
    def create(cls, name: str, **options: Any) -> "GradingPolicy":
        try:
            policy_class = cls._registry[name]
        except KeyError:
            raise ValueError(f"Невідома політика оцінювання: {name!r}") from None
        return policy_class(**options)

    @abstractmethod
    def average(self, results: Iterable[CourseResult]) -> Grade | None: ...

class CreditWeightedAverage(GradingPolicy, name="weighted"):
    def average(self, results: Iterable[CourseResult]) -> Grade | None:
        items = list(results)
        credits = sum(result.credits for result in items)
        if not credits:
            return None
        points = sum((result.grade.value * result.credits for result in items), Decimal(0))
        return Grade(points / credits)

# class BudgetStudent(Student)
def has_scholarship(self, policy: GradingPolicy) -> bool:
    average = self.average(policy)
    return average is not None and average >= SCHOLARSHIP_MINIMUM

Composition (has-a): студент має AcademicRecord і GroupCode, запис має CourseResult, група має студентів, реєстр має два репозиторії, сервіс – реєстр, notifier і політику. Encapsulation: full_name – property без setter, Group.members і AcademicRecord.results повертають копію-кортеж, а студент потрапляє в групу лише через Group.add, який узгоджує поле student.group.

@property
def full_name(self) -> str:
    return f"{self.first_name} {self.last_name}"

@property
def members(self) -> tuple[Student, ...]:
    return tuple(self._members.values())

def add(self, student: Student) -> None:
    if student.id in self._members:
        raise DuplicateKeyError(f"Студент {student.id} уже є в групі {self._code}")
    self._members[student.id] = student
    student.group = self._code

4. Dataclass і immutable value object

Grade – frozen dataclass зі slots=True: незмінний, hashable, порівнюється за значенням. У __post_init__ перевіряється діапазон 0–100 і значення нормалізується до сотих; total_ordering добудовує <= > >= з __lt__, of() свідомо не приймає float, а level – property з рівнем успішності. Student – змінюваний dataclass з eq=False: рівність і хеш визначає лише id (entity), а поля перевіряються в __post_init__.

@total_ordering
@dataclass(frozen=True, slots=True)
class Grade:
    value: Decimal

    def __post_init__(self) -> None:
        if not isinstance(self.value, Decimal):
            raise TypeError("value має бути Decimal; використовуйте Grade.of()")
        if not self.value.is_finite() or not 0 <= self.value <= MAX_POINTS:
            raise InvalidGradeError(f"Оцінка поза межами 0-100: {self.value}")
        object.__setattr__(self, "value", self.value.quantize(HUNDREDTH, ROUND_HALF_UP))

    @classmethod
    def of(cls, value: Decimal | int | str) -> Self:
        if isinstance(value, float):
            raise TypeError("float не підходить для оцінок: використовуйте str або Decimal")
        try:
            return cls(Decimal(value))
        except InvalidOperation:

5. ABC, Protocol, generics і TypedDict

Repository – ABC (nominal typing) і водночас generic class. K – constrained TypeVar (ключ лише int або GroupCode), T – звичайний TypeVar, S у реєстрі й сервісі – bound TypeVar: register(BudgetStudent(...)) повертає саме BudgetStudent.

K = TypeVar("K", int, GroupCode)
T = TypeVar("T")
S = TypeVar("S", bound=Student)

class Repository(ABC, Generic[K, T]):
    @abstractmethod
    def add(self, item: T) -> None: ...

    @abstractmethod
    def get(self, key: K) -> T | None: ...

    @abstractmethod
    def remove(self, key: K) -> bool: ...

    @abstractmethod
    def __iter__(self) -> Iterator[T]: ...

    @abstractmethod
    def __len__(self) -> int: ...

    def find(self, predicate: Callable[[T], bool]) -> list[T]:
        return [item for item in self if predicate(item)]

Notifier – Protocol (structural typing): адаптери його не успадковують, але сумісні за сигнатурою send; завдяки @runtime_checkable працює isinstance. Три вузькі протоколи Parser, Validator, Formatter – interface segregation. TypedDict описує зовнішній JSON-payload студента; під час виконання це звичайний dict, тому його перетворює на доменний об'єкт student_from_payload.

@runtime_checkable
class Notifier(Protocol):
    def send(self, recipient: str, message: str) -> None: ...

6. Application service, dependency injection і SOLID

StudentService отримує реєстр, notifier і політику через конструктор і залежить лише від абстракцій; конкретні класи створюються в одному місці – composition root (build_registry, build_services). Один реєстр можна під'єднати до сервісів із різними notifier.

def __init__(
    self,
    registry: StudentRegistry,
    notifier: Notifier,
    policy: GradingPolicy,
) -> None:
    self._registry = registry
    self._notifier = notifier
    self._policy = policy

def register(self, student: S) -> S:
    self._registry.add_student(student)
    self._notify(student, f"вас зараховано до групи {student.group} ({student.funding})")
    return student

def build_registry() -> StudentRegistry:
    students = InMemoryRepository[int, Student](key=lambda student: student.id)
    groups = InMemoryRepository[GroupCode, Group](key=lambda group: group.code)
    return StudentRegistry(students, groups)

def build_services(
    registry: StudentRegistry, notifier: Notifier, policy: GradingPolicy
) -> tuple[StudentService, ReportService]:
    return StudentService(registry, notifier, policy), ReportService(registry, policy)
